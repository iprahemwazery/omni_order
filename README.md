# أومني أوردر (Omni Order)

نظام إدارة محلات (سوبر ماركت / بقالة) يعمل على الموبايل والتابلت:
**مخزون + مبيعات + فواتير** بتخزين محلي كامل على الجهاز.

## المزايا

- **المخزون**: إضافة / تعديل / حذف الأصناف (اسم + سعر إجباري + كمية + وحدة قياس).
- **المبيعات (POS)**: كل الأصناف أمامك، تضغط على الصنف وتختار الكمية،
  يحسب إجمالي السطر تلقائيًا مع الإجمالي الكلي، وتكتمل الفاتورة.
- **الفاتورة (شيك)**: تصميم ورقي مريح للعين، باسم المتجر وتاريخه وتفاصيله.
- **سجل المبيعات**: كل الفواتير السابقة قابلة للرجوع إليها.
- **تخزين محلي**: SQLite على الجهاز — لا يحتاج إنترنت أو حساب.
- **إعدادات**: اسم المتجر والهاتف والعملة (تظهر على الفاتورة).
- **تصميم متجاوب**: في الموبايل تظهر السلة كشريط سفلي، وفي التابلت لوحة جانبية دائمة.

## التشغيل

```bash
flutter pub get
flutter run                # على جهاز/محاكي متصل
flutter build apk --release  # بناء ملف Android
```

## معمارية الكود (Clean Architecture)

```
lib/
├── core/          # الثيم، الألوان، الفورمات، الثوابت
├── domain/        # النماذج (Product, Sale, Cart...) + واجهة StoreRepository
├── data/          # AppDatabase (SQLite) + تنفيذ StoreRepositoryImpl
└── presentation/  # StoreProvider (حالة التطبيق) + الشاشات + الـ Widgets
```

- طبقة `domain` لا تعرف أي شيء عن قاعدة البيانات.
- طبقة `presentation` تتعامل مع `StoreRepository` (واجهة) فقط،
  مما يسهّل الاختبار (يوجد `FakeStoreRepository` في `test/fakes`).
